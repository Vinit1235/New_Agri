STEP 4: CONFIGURE SETTINGS (5 minutes)
═══════════════════════════════════════════════════════════════

A) WiFi Credentials (around line 10):
   ─────────────────────────────────────────────────────────
   const char* WIFI_SSID     = "YOUR_WIFI_SSID";
   const char* WIFI_PASSWORD = "YOUR_WIFI_PASSWORD";
   
   CHANGE TO:
   const char* WIFI_SSID     = "YourActualWiFiName";
   const char* WIFI_PASSWORD = "YourActualPassword";
   ─────────────────────────────────────────────────────────

B) Get Your PC's IP Address:
   ─────────────────────────────────────────────────────────
   Open PowerShell (Win + X → Windows PowerShell):
   
   > ipconfig
   
   Look for "IPv4 Address": 192.168.1.XXX
   ─────────────────────────────────────────────────────────

C) Backend URL (around line 17):
   ─────────────────────────────────────────────────────────
   const char* BACKEND_URL = "http://192.168.1.100:8000/api/telemetry";
   
   CHANGE TO:
   const char* BACKEND_URL = "http://192.168.1.XXX:8000/api/telemetry";
                                         ↑ Your actual IP
   ─────────────────────────────────────────────────────────

D) Device Token (around line 20):
   ─────────────────────────────────────────────────────────
   Option 1: Use existing device from dashboard
   Option 2: Register new device via API (see full guide)
   
   const char* DEVICE_ID    = "ESP32_FIELD_NODE_001";
   const char* DEVICE_TOKEN = "paste_your_token_here";
   ─────────────────────────────────────────────────────────

❌ TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════

"No COM port detected"
→ Install CP210x USB drivers from Silicon Labs
→ Try different USB cable

"Upload failed: Timed out"
→ Hold BOOT button during upload
→ Lower upload speed to 57600

"WiFi connection failed"
→ Check SSID/password (case-sensitive!)
→ Use 2.4GHz WiFi (not 5GHz)

"Telemetry failed: connection refused"
→ Check backend is running: uvicorn app.main:app --reload
→ Verify IP address with ipconfig
→ Disable Windows Firewall temporarily

"HTTP 401 Unauthorized"
→ Device token is invalid
→ Re-register device
→ Update token in firmware
