ESP32 multi-sensor station — complete wiring reference

Every physical wire, from the 12V input to each ESP32 GPIO pin. No connection is abstracted or summarized — the diagram and the tables below describe the same wires twice, in two formats, so nothing is lost between them.

Reading this diagram: a small gap in the black GND line marks a crossing, not a connection — three +5V drops (to the pH module, the EC module, and ESP32 VIN) physically pass over the GND rail on their way down without touching it. Every other line junction shown is a real electrical connection.

Voltage divider reference (used identically for both pH and EC, as two separate circuits):
Vout = Vin × R2 / (R1 + R2)
With R1 = 5.6kΩ, R2 = 10kΩ: Vout = 5V × 10/(15.6) ≈ 3.21V max
In firmware, multiply the raw ADC voltage back by 1.56 to reconstruct the sensor's true 0–5V output.

7. Before you power it on

  • LM2596 trimmed to exactly 5.00V, measured with a multimeter, before the ESP32 or any sensor is connected
  • 5V rail never touches the ESP32 3V3 pin
  • pH and EC each have their own separate 5.6kΩ/10kΩ divider — they are not sharing one
  • 10kΩ pull-up fitted between DHT11 DATA and VCC if using a bare 4-pin sensor
  • Every GND pin — supply, LM2596, ESP32, and all four sensors — ties to one common ground point
  • Only GPIO32, 34, and 35 are used for analog reads (all ADC1, safe with Wi-Fi active)
